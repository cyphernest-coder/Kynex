/ HOW IT WORKS

What does a password strength checker look for?

A useful password assessment considers more than just the number of characters.

📏

Length

Longer passwords generally provide a much larger search space than short passwords.

🔤

Variety

Mixing uppercase and lowercase letters, numbers, and symbols can increase character diversity.

🧠

Patterns

Repeated characters, common words, sequences, and predictable substitutions can weaken passwords.

/ PASSWORD SECURITY

What makes a password stronger?

Good password security is mostly about making guessing difficult and avoiding reuse.

1

Make it long

Prefer a long password or passphrase rather than relying only on complicated symbols.

2

Keep it unique

Avoid using the same password across multiple accounts.

3

Avoid predictable patterns

Avoid names, dates, keyboard sequences, repeated characters, and common substitutions.

4

Consider a password manager

A reputable password manager can generate and remember unique passwords for different accounts.
